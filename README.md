
# Campus Study Room Booking System

Team Red implementation for CSC 430 final project.

## How to run

1. Install Node.js.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000/login.html` in a browser.

double booking prevention, check in, auto cancel of no shows after 15 minutes, and simple
